17. OFFSET 
OFFSET tells MySQL how many rows to skip 
SELECT * FROM users LIMIT 10 OFFSET 20;
Meaning:

Skip 20 rows, then return 10.
Think:

OFFSET 0 → rows 1-10
OFFSET 10 → rows 11-20
OFFSET 20 → rows 21-30

This is commonly used for pagination.

=============================================================================================

18. Pagination

Suppose frontend sends:

?page=3&limit=10

You calculate:

offset = (page - 1) × limit

Therefore:

page 1 → offset 0
page 2 → offset 10
page 3 → offset 20

Query:

SELECT id, title, status
FROM tasks
ORDER BY created_at DESC
LIMIT 10 OFFSET 20;

This is something you'll almost certainly encounter in backend work.
